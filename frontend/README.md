# 손끝진료 프런트엔드

React와 Vite로 만든 의료 수어 소통 화면입니다. 진료실 번역은 **수어 촬영 → 단어 확인 → 문장 완성** 순서로 진행합니다. 가입하지 않아도 번역을 시작할 수 있습니다.

## 실행

Python 분석 API를 `http://localhost:8000`, Spring Boot 백엔드를 `http://localhost:8080`에서 실행한 뒤:

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열고 카메라 권한을 허용합니다. 카메라는 `localhost` 또는 HTTPS에서 사용해야 합니다. API 주소가 다르면 `.env.example`을 복사해 `.env`에 주소를 설정합니다.

## 번역 흐름

1. 촬영 화면에서 수어를 녹화하고 종료합니다. 촬영 도움말은 화면 오른쪽 위의 작은 버튼에서 엽니다.
2. 영상 분석이 시작되면 단어 확인 화면으로 자동 이동합니다. 인식된 단어는 최대 5개까지 순서대로 모이며, 개별·전체 삭제와 추가 촬영을 할 수 있습니다.
3. 단어 확인 화면의 **문장 만들기**를 누르면 Spring Boot의 `POST /api/translations`로 단어를 전송합니다. 완성 문장을 의사에게 보여주거나 단어 확인으로 돌아갈 수 있습니다.

촬영 영상은 Python API의 `POST /api/sign/analyze`로 전송됩니다. Python 분석 서버의 임시 영상은 요청 처리 후 삭제됩니다. **진단용 영상 저장**을 누를 때만 마지막 촬영 영상이 사용자의 기기에 저장됩니다.

## 가입 화면 상태

데스크톱용 단계별 가입 화면은 로그인 방법 선택, 이름, 생년월일, 추가로 알릴 사항, 확인 화면으로 구성했습니다. 기존 질환과 수술 이력 질문은 없습니다.

현재 저장소에는 카카오 인증, 문자 인증, 계정 저장 API가 없습니다. 개발 환경에서는 **가입 화면 미리보기**로 질문 흐름을 살펴볼 수 있지만, 입력 내용은 저장되지 않으며 실제 로그인이 완료된 것으로 표시하지 않습니다. 카카오·전화번호 버튼은 인증 서비스가 연결되지 않았다는 상태를 안내합니다. 실제 가입을 운영하려면 인증 제공자 설정과 백엔드 API가 필요합니다.
